NFC Tag Reader

Tap “Scan”, then hold the back of your phone against a tag.

Not supported

Web NFC only works in Chrome on Android, over HTTPS, on a phone with NFC turned on. iPhone (Safari/Chrome) does not support reading NFC from web pages.

iPhone

iPhone browsers can't read NFC, and the Shortcuts app can't pass tag data to a web page. Use an Android phone with Chrome, or an iOS NFC app.

This page can still display tag data passed in the URL: ?id=&payload=, hex= or b64=.
